## [Bandit Wargames](https://overthewire.org/wargames/bandit/)

The Bandit wargame is organized by levels, where the goal is to find information on how to progress to the next level. It starts at level 0 and goes to level 34. There will usually be a clue on the level page for what tools to use.  The ```man <command>``` command will come in handy, along with google, a great deal here.

### Vital SSH info:
  Host: bandit.labs.overthewire.org
  Port: 2220
