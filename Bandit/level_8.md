## Level 8

New level new command.  This times it's ```grep```, which stands for global regular expression print, not a very first hint to its use I think, besides printing.  
It is used to search for text or patterns in a file, like keywords and such, and will print the lines containing the element you are searching for.  Ex) ```grep "keyword" example.txt``` would print ```keyword and anything else on the line```. Flags are placed before the elements to be searched for, ie ```grep -<flag> keyword example.txt```. It can also search across multiple files by just including the file type you wish to search, like so: ```grep keyword *.txt```
