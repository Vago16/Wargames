## Level 0
Level 0 is the setup level and prepares you to get comfortable with logging in remotely to the host server. 
Using the command: ```ssh bandit0@bandit.labs.overthewire.org -p 2220``` and entering in the password "**bandit0**" gets you logged in.

*Once done with ssh session, type "exit" in terminal and press enter key to log out of the session.
