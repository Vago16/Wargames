## Level 2
Once again, we use ```cat```, but with a trick this time to read the file since it is just a singular dash. Normally a dash refers to command line options or flags, so the terminal will be confused if you do the same thing as you did last level.
Instead, add a ```./``` to the front of the dash to tell the terminal that it is a file and not an argument.  The full command is now:
```cat ./-```
